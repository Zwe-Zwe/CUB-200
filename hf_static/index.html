Model. ConvNeXt-Tiny, pretrained on ImageNet-1k and fine-tuned on 4,829 CUB-200 training images. It was chosen by a step-by-step tuning ladder (linear probe, then fine-tuning with two learning rates, regularisation, longer training, then 224 to 448 px progressive resizing), and finally retrained on all training data. The test set was used only once, for the final numbers above.

Reading the confidence. Training used label smoothing (0.1), which deliberately keeps the confidence below 100%, so a correct answer often shows 50 to 90%. Most mistakes are between near-identical sibling species (gulls, terns, crows and blackbirds). The model only knows these 200 species, so any other image is still mapped to one of them.

Preprocessing exactly as in evaluation: shorter side resized to 512 px, centre crop 448 px, ImageNet normalisation. Runtime: ONNX Runtime Web (-).
