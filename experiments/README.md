# Experiment records

Evidence base for the report. Two kinds of record:

1. **Experiment notes** (`EXP-*.md`, hand-written): the question, hypothesis, setup, results, observations and
   conclusion of each experiment, with links to the evidence.
2. **Run cards** (`runs/<run>.md`, generated by `python -m birdcls.report`): the full record of every training run:
   configuration, per-epoch log, curves, test results. Generated from the files in `outputs/runs/`, so they always
   match the saved checkpoints and logs. Overview: [runs/INDEX.md](runs/INDEX.md).

`Progress.md` (project root) is the short running summary and timeline.

## Conventions

- **Run name** = `<model>__<config>`, folder `outputs/runs/<run>/`.
- **Selection rule:** every choice (early stopping, best epoch, best run, TTA on/off) uses validation accuracy.
  Test numbers are reported, never used to choose.
- **Ladder steps (Track 1) are compared without TTA** (single forward pass), so each step changes exactly one thing.
  TTA is a test-time choice; it is reported for every run but decided once, for the final model, on validation.
- **Noise level:** the test set has 1,204 images, so one image = 0.083 pp and the standard error of a Top-1 around
  85 to 94% is about ±0.7 to 1.0 pp. Differences below about 1 pp from a single run are not conclusive.
- **Paired test for small differences:** when two runs differ by about 2 pp or less, compare them on the *same* images
  with McNemar's exact test (counts of images only one model gets right). It is more sensitive than comparing two
  accuracies, and it is reported in the experiment note (first used in EXP-09).
- **Full-train runs** (`--full-train`, suffix `__full`) retrain an already-chosen recipe on train + val. They have no
  validation score (NaN), keep the final epoch, and are evaluated on test exactly once.
- After every training or evaluation: `python -m birdcls.evaluate --runs <run>` then `python -m birdcls.report`,
  then update the experiment note.
